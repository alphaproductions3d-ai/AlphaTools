Alpha Send to UnrealAlpha Send to Unreal

Alpha Send to Unreal exports a Mixamo-rigged character from Blender in a form Unreal Engine can import. In one click it writes the FBX, copies the textures with standard names and creates a manifest.json that describes the materials.

Alpha Send to Unreal exporta un personaje con rig de Mixamo desde Blender en un formato que Unreal Engine puede importar. Con un clic escribe el FBX, copia las texturas con nombres estándar y crea un manifest.json que describe los materiales.

Part of Alpha ToolsParte de Alpha Tools

This add-on is the Blender half of Alpha Tools. It is meant to be used together with the Alpha Tools plugin for Unreal Engine, which reads this export and builds the materials and the playable character. Both are published together on GitHub, each with its own manual.

Este addon es la parte de Blender de Alpha Tools. Está pensado para usarse junto con el plugin Alpha Tools para Unreal Engine, que lee esta exportación y crea los materiales y el personaje jugable. Ambos se publican juntos en GitHub, cada uno con su manual.

What it doesQué hace

  • Adds a temporary root bone above Hips for the export (Unreal's retargeting expects it) and removes it afterwards.Añade un hueso root temporal sobre Hips durante la exportación (el retargeting de Unreal lo espera) y lo elimina después.
  • Copies the Base Color, Normal, ORM and Emissive textures as <Material>_BaseColor, _Normal, _ORM and _Emissive.Copia las texturas Base Color, Normal, ORM y Emissive como <Material>_BaseColor, _Normal, _ORM y _Emissive.
  • Lets you choose how each transparent material is used: Default, Glass or Cutout.Te deja elegir cómo se usa cada material transparente: Default, Glass o Cutout.

What it does not doQué no hace

  • It only supports the Mixamo skeleton.Solo soporta el esqueleto de Mixamo.
  • It does not export animations (the Unreal plugin retargets the Mannequin animations).No exporta animaciones (el plugin de Unreal retargetea las animaciones del Mannequin).
  • It does not bake or edit textures, and it does not support UDIM tiles.No hace bake ni edita texturas, y no soporta tiles UDIM.

RequirementsRequisitos

  • Blender 5.2 or newer. The normal map convention differs between Blender versions, so older ones are not supported.Blender 5.2 o superior. La convención de normal maps cambia entre versiones de Blender, por eso las anteriores no están soportadas.
  • A character with the Mixamo skeleton and at least one visible mesh bound to the armature (Armature modifier).Un personaje con el esqueleto de Mixamo y al menos una malla visible ligada al armature (modificador Armature).
  • Materials with a Principled BSDF whose textures are Image Texture nodes connected directly.Materiales con Principled BSDF cuyas texturas son nodos Image Texture conectados directamente.
  • NumPy (included with Blender) is used only to separate the solid parts of Glass materials.NumPy (incluido en Blender) solo se usa para separar las partes sólidas de los materiales Glass.

InstallationInstalación

  1. Remove any older version of the add-on (Edit > Preferences > Get Extensions).Quita cualquier versión anterior del addon (Edit > Preferences > Get Extensions).
  2. In Get Extensions, open the dropdown at the top right and choose Install from Disk. Select alpha_send_to_unreal-0.3.0.zip.En Get Extensions, abre el menú desplegable de arriba a la derecha y elige Install from Disk. Selecciona alpha_send_to_unreal-0.3.0.zip.
  3. Make sure the add-on is enabled.Comprueba que el addon esté activado.
  4. In the 3D Viewport press N and open the Send to Unreal tab.En el 3D Viewport pulsa N y abre la pestaña Send to Unreal.

WorkflowFlujo de trabajo

  1. Save your .blend file, or choose an Export Folder.Guarda tu archivo .blend, o elige una carpeta de exportación.
  2. Be in Object Mode and select the armature or one of its meshes.Estate en Object Mode y selecciona el armature o una de sus mallas.
  3. In Transparency, set Default, Glass or Cutout for each material that has alpha.En Transparency, elige Default, Glass o Cutout para cada material que tenga alpha.
  4. Click Send to Unreal.Pulsa Send to Unreal.
  5. The add-on creates a folder SK_<name> with SK_<name>.fbx, a textures folder and manifest.json.El addon crea una carpeta SK_<nombre> con SK_<nombre>.fbx, una carpeta textures y manifest.json.
  6. Continue in Unreal Engine with the Alpha Tools plugin (see its manual).Continúa en Unreal Engine con el plugin Alpha Tools (consulta su manual).
Keep the export folderConserva la carpeta de exportación

Import the FBX into Unreal from this folder and leave the folder where it is. The Unreal plugin finds manifest.json and the textures next to the original FBX. If you move or delete the folder, run the export again.

Importa el FBX en Unreal desde esta carpeta y déjala donde está. El plugin de Unreal busca manifest.json y las texturas junto al FBX original. Si mueves o borras la carpeta, vuelve a exportar.

Panel referenceReferencia del panel

  • Export Folder (default //): where the character folder is created. // means next to the saved .blend.Export Folder (por defecto //): dónde se crea la carpeta del personaje. // significa junto al .blend guardado.
  • Name: character name. Empty uses the first mesh name. SK_ is added in front when it is missing.Name: nombre del personaje. Vacío usa el nombre de la primera malla. Se añade SK_ delante si falta.
  • Add Root Bone (on by default): adds a temporary root and removes it after the export. If the armature already has a root bone, none is added.Add Root Bone (activado por defecto): añade un root temporal y lo elimina tras exportar. Si el armature ya tiene un hueso root, no se añade otro.
  • Open Folder After Export (off by default): shows the export folder in your file browser.Open Folder After Export (desactivado por defecto): muestra la carpeta de exportación en tu explorador de archivos.
  • Support > Documentation: opens this manual in your browser.Support > Documentation: abre este manual en tu navegador.

TransparencyTransparency

Only materials that have alpha are listed.

Solo se listan los materiales que tienen alpha.

  • Default (ignore alpha): exported as a normal opaque material.Default (ignore alpha): se exporta como un material opaco normal.
  • Glass (translucent): for glass, liquids and clear plastic. Solid parts in the same material (cork, metal, leather…) are separated automatically while exporting; your scene is not changed.Glass (translucent): para vidrio, líquidos y plástico transparente. Las partes sólidas del mismo material (corcho, metal, cuero…) se separan automáticamente al exportar; tu escena no cambia.
  • Cutout (alpha clip): for leaves, hair cards, fences and flags. Transparent areas are cut away and the material is two-sided.Cutout (alpha clip): para hojas, hair cards, vallas y banderas. Las zonas transparentes se recortan y el material es de doble cara.

What it changes in the sceneQué cambia en la escena

Nothing is left behind. The temporary root bone and the temporary Glass splits are removed even if the export fails. Your original images are not modified.

No queda nada. El hueso root temporal y las divisiones temporales de Glass se eliminan incluso si la exportación falla. Tus imágenes originales no se modifican.

Files written, all inside the export folder: the FBX, copies of the textures and manifest.json.

Archivos escritos, todos dentro de la carpeta de exportación: el FBX, copias de las texturas y manifest.json.

FAQ and troubleshootingFAQ y solución de problemas

Errors (the export stops)Errores (la exportación se detiene)

Select the character's armature or one of its meshes.

Selecciona el armature del personaje o una de sus mallas.

The export only runs in Object Mode.

La exportación solo funciona en Object Mode.

Show the armature and the meshes you want to export. Hidden meshes are skipped.

Muestra el armature y las mallas que quieres exportar. Las mallas ocultas se omiten.

The mesh needs an Armature modifier or a parent armature.

La malla necesita un modificador Armature o un armature como padre.

The default folder // is relative to the saved .blend. Save the file or choose a folder.

La carpeta por defecto // es relativa al .blend guardado. Guarda el archivo o elige una carpeta.

Use a normal single image for that material.

Usa una imagen normal única para ese material.

Glass needs UVs to separate its solid faces. Add a UV map or use another alpha mode.

Glass necesita UVs para separar sus caras sólidas. Añade un UV map o usa otro modo de alpha.

Glass needs NumPy, which normally ships with Blender. Use another alpha mode or reinstall Blender.

Glass necesita NumPy, que normalmente viene con Blender. Usa otro modo de alpha o reinstala Blender.

Warnings (the export continues)Avisos (la exportación continúa)

Apply the scale (Ctrl+A) if the character looks stretched in Unreal.

Aplica la escala (Ctrl+A) si el personaje se ve estirado en Unreal.

Without an Armature modifier the mesh may not deform.

Sin modificador Armature la malla puede no deformarse.

Unreal may import the skeleton oddly.

Unreal puede importar el esqueleto de forma extraña.

Connect an Image Texture directly to Base Color, and a Normal Map node (with an image) to Normal. Otherwise that texture is not exported.

Conecta una Image Texture directamente a Base Color, y un nodo Normal Map (con imagen) a Normal. Si no, esa textura no se exporta.

Only the Roughness image is exported.

Solo se exporta la imagen de Roughness.

JPEG cannot store transparency. Use PNG or another format with alpha.

JPEG no guarda transparencia. Usa PNG u otro formato con alpha.

Connect the Base Color image's Alpha output to the BSDF Alpha input.

Conecta la salida Alpha de la imagen de Base Color a la entrada Alpha del BSDF.
